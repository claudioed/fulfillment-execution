Package's derived WES-tier sortation routing decision (see [ADR-0010](/docs/adr/0010-package-segregation-and-sort-lane)): `HAZMAT_LANE` if any scanned item carried a DOT hazard class from the live per-scanned-item classification lookup, else `FRAGILE_NO_TILT` if `fragileHandling` is true, else `STANDARD`. A decision only — no WCS device/conveyor integration exists in this service; a real WCS system would consume this value as its own inbound fact.
